# Ruang Belajar Muslim Jepang (RBMJ) Website

Website statis untuk komunitas **Ruang Belajar Muslim Jepang**.  
Dibangun dengan HTML + TailwindCSS, di-host gratis dengan **GitHub Pages**.

## 🌐 Live Website
👉 [https://ruangbelajarjapan1-cloud.github.io/rbj-site/](https://ruangbelajarjapan1-cloud.github.io/rbj-site/)

## 📂 Struktur Folder
```
rbj-site/
├── index.html       # Landing page utama
├── tentang.html     # Tentang komunitas
├── program.html     # Program, jadwal, form pendaftaran
├── artikel.html     # Artikel & informasi
├── galeri.html      # Galeri foto kegiatan
├── kontak.html      # Kontak & form
└── assets/          # Logo & gambar
    ├── logo.jpg
    ├── hero.jpg
    ├── g1.jpg .. g4.jpg
```

## 🚀 Cara Update Website
1. Edit file HTML di laptop/PC kamu.
2. Upload ulang ke GitHub repo → commit changes.
3. Perubahan langsung tampil di GitHub Pages.

## 🔧 Customisasi
- **Program & Jadwal**: ubah `program.html`, ganti link **Google Form** & **Google Calendar**.
- **Kontak**: edit `kontak.html` → update email, WhatsApp, Instagram.
- **Gambar**: ganti file di `assets/` (logo, hero, galeri).

## 💡 Tips
- Kalau mau domain custom (misalnya `rbmj.org`), bisa diatur di GitHub Pages Settings.
- Untuk form HTML aktif → bisa pakai **Google Apps Script** atau **Formspree**.
